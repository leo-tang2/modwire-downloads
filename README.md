# Modwire desktop downloads

Version 0.1.18 public test builds for Windows x64 and Apple Silicon Mac.

- [Windows installer](./Modwire_0.1.18_x64-setup.exe) — unsigned.
- [Apple Silicon installer](./Modwire_0.1.18_aarch64.dmg) — ad-hoc signed and not notarized; macOS may block opening it.
- [File sizes and SHA-256 checksums](./release-0.1.18.json)

Downloads require no GitHub account. These packages add the redesigned Build a Mod screen, mod-loader support, sharper game library art and the in-app Community catalog. Game compatibility remains in testing; packaging and automated checks do not establish successful in-game mods.

Application source stays in the private repository. Older installers are preserved for reference. Required third-party notices are included in each installer.
