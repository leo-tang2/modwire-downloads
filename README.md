# Modwire public test installers

Windows: 0.1.16. Mac: 0.1.15.

Download without a GitHub or Vercel login: https://modwire-gamma.vercel.app/downloads/

Repairs interrupted publisher checks, including Outer Wilds. A lost response resumes from its saved receipt. A missing request can continue only after the server prevents its original ID from ever being submitted. Completed chat replies remain bound to their original conversation. Pending or uncertain provider usage is never automatically resubmitted.

165 backend, 216 native and 46 frontend automated tests passed. Read-only discovery covered 20 installed Windows games; 10 candidates passed current metadata and Nexus identity checks. Provider responses in regression tests were synthetic.

Windows 0.1.16 is unsigned. The Mac download remains the separately tested 0.1.15 ad-hoc/non-notarized build and does not include the new native recovery changes. No AI generation, payment, email, gameplay or game-file change was used in this acceptance. No claim of working mods for every game is made. Public email delivery still requires the previously documented sender-domain/SMTP setup. The separate Universal Modder creation preview is being integrated independently.
