# Modwire desktop downloads

Version 0.1.17 public test builds for Windows x64 and Apple Silicon Mac.

- [Windows installer](./Modwire_0.1.17_x64-setup.exe) — unsigned.
- [Apple Silicon installer](./Modwire_0.1.17_aarch64.dmg) — ad-hoc signed and not notarized; macOS may block opening it.
- [File sizes and SHA-256 checksums](./release-0.1.17.json)

Downloads require no GitHub account. These packages contain the dev.4-derived mod workshop and recovery updates. Game compatibility remains in testing; packaging and automated checks do not establish successful in-game mods.

Application source stays in the private repository. Older installers are preserved for reference. Required third-party notices are included in each installer.
