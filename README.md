# Modwire desktop downloads

Version 0.1.19 public test builds for Windows x64 and Apple Silicon Mac.

- [Windows installer](./Modwire_0.1.19_x64-setup.exe) — unsigned.
- [Apple Silicon installer](./Modwire_0.1.19_aarch64.dmg) — ad-hoc signed and not notarized; macOS may block opening it.
- [File sizes and SHA-256 checksums](./release-0.1.19.json)

Downloads require no GitHub account. These packages add the new Profile and Community screens, an icon sidebar and safety fixes from a review of 0.1.18. Game compatibility remains in testing; packaging and automated checks do not establish successful in-game mods.

Application source stays in the private repository. Older installers are preserved for reference. Required third-party notices are included in each installer.
